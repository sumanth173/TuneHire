# TuneHire — Complete Scaffold (Dev) 
This package contains a more complete development scaffold for **TuneHire** (Angular 19 frontend + ASP.NET Web API backend + SQL Server).

**What's included**
- backend/: ASP.NET Web API (models, DbContext, controllers for Auth, Musicians, Bookings, Reviews, Payments), SignalR hub, seed data service, appsettings.json, csproj.
- frontend/: Angular 19 app with Angular Material, services, components (home, musicians, musician-detail, booking flow, auth), environment files.
- sql/: create_tunehire_db.sql
- run_instructions.txt — step-by-step to run locally

This is for development and learning — not production ready. Follow README notes for configuration.
